# Repository guidance

This repository stores personal workflow documentation in Markdown. Use README.md as the entry point and keep section indexes current when adding or moving documents. Preserve existing content and use relative links.

Read `.agents/skills/add-n/SKILL.md` when asked to capture or add a note, and `.agents/skills/add-bm/SKILL.md` when asked to save or categorize bookmarks. Templates live in `templates/`. Keep other documentation changes scoped to the request.

Use the supplied facts; do not invent meeting participants, decisions, deadlines, bookmark URLs, or page contents. Use the current local date for capture dates unless the user specifies another date. A saved internal link does not require fetching the page.
